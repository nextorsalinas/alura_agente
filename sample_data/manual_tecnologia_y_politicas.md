# MANUAL INTERNO DE TECNOLOGÍA Y POLÍTICAS DE LA EMPRESA

## 1. Arquitectura de Sistemas y Stack Tecnológico

### 1.1 Plataforma de Ventas e E-commerce
- **Front-end (Interfaz de usuario):** Desarrollado con React.js, TypeScript y Tailwind CSS.
- **Back-end (Servidores y APIs):** Desarrollado principalmente en **Python (FastAPI)** para microservicios de Inteligencia Artificial, y **Go (Golang)** junto con **Node.js (NestJS)** para el procesamiento masivo de transacciones de ventas y gestión de inventario.
- **Base de Datos:** PostgreSQL para datos relacionales, Redis para almacenamiento en caché y MongoDB para registros de auditoría.
- **Infraestructura Cloud:** Google Cloud Platform (GCP) utilizando Cloud Run para contenedores serverless, GKE (Google Kubernetes Engine) para servicios centrales y Cloud Storage para archivos.

### 1.2 Seguridad e Identidad
- **Autenticación:** OAuth2 / OpenID Connect con Google Workspace e Identity Platform.
- **Gestión de Secretos:** GCP Secret Manager para claves de API y credenciales de base de datos.

## 2. Políticas Internas de Recursos Humanos

### 2.1 Modalidad de Trabajo y Horarios
- **Modalidad:** Trabajo híbrido/remoto con flexibilidad de horarios. Se requiere presencia en oficina 2 días a la semana para equipos locales.
- **Horario Central:** Disponibilidad esperada entre las 10:00 y las 16:00 horas (Zona Horaria Local).

### 2.2 Capacitaciones y Presupuesto Educativo
- Cada colaborador/a dispone de un presupuesto anual de $1,000 USD para cursos, certificaciones (como Google Cloud Certified, AWS, Azure, Alura) y asistencia a conferencias tech.
